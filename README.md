# AI

## NichirinScript: un lenguaje inspirado en Kimetsu no Yaiba

NichirinScript es un lenguaje de programación de diseño experimental que fusiona la estética y el folclore de *Kimetsu no Yaiba* con principios modernos de programación. El archivo [`docs/NichirinScript.md`](docs/NichirinScript.md) recopila la mitología, la gramática y los ejemplos de uso del lenguaje.

> "Respira hondo, afila tu voluntad y deja que tu código corte como una katana nichirin." 

## Contenido del repositorio

- `docs/NichirinScript.md`: Documento principal que narra el lore y la especificación del lenguaje.

## Cómo contribuir

Sigue el espíritu del Cuerpo de Exterminio de Demonios:

1. **Respira** (*Total Concentration Constant*): lee la documentación y mantén el código en armonía con la narrativa establecida.
2. **Afilado de Nichirin**: propone nuevas formas, estilos de respiración o mejoras sintácticas coherentes con el universo Kimetsu.
3. **Reporte Kasugai**: abre un issue describiendo la propuesta y espera la señal del cuervo mensajero antes de iniciar una misión.
